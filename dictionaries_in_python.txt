1. Task CREATING DICTIONARY with name, Batch, role, , sem_marks(from 1st year), viisted_location, hobbies
student = {
    "name": "Indumathi",
    "cgpa": 8.5
}
2. ACCESS VALUES
# Using Key
print(student["name"]) # Rahul
# SAFE METHOD for million users-> get()
print(student.get("name")) #None

3. ADD NEW KEY-VALUE pair to existing dict
student["fav_movie"] = ["kantara",'kanchana','3']
4. MODIFY VALUE
student["Batch"] = 2020

5. REMOVE ELEMENTS(pop(), del, clear())
# pop()
student.pop("Batch")
# del
del student["location"]
# clear()
student.clear() # Removes everything

6. GET ALL KEYS
print(student.keys())
7. GET ALL VALUES
print(student.values())
8. GET KEY-VALUE PAIRS
print(student.items())

9. DICTIONARY through Loops
# Loop Keys
for i in student:
    print(i) # All keys only

# Loop Values
for value in student.values():
    print(value) # All values
# Loop Key-Value Pairs
for key, value in student.items():
    print(key, value)

10. CHECK KEY EXISTENCE
print("name" in student) # True
11. FIND LENGTH
print(len(student))
print(len(student['key']))

12. COPY DICTIONARY(Duplicate)
new_student = student.copy()
13. UPDATE DICTIONARY
student.update({
    "role": "Backend Developer"
})
student['role'] = 'Backend Developer'

Method       Purpose              
 get()    | Safe access          
 keys()   | Get all keys         
 values() | Get all values       
 items()  | Get key-value pairs  
 update() | Modify data          
 pop()    | Remove key           
 clear()  | Empty dictionary     
 copy()   | Duplicate dictionary
