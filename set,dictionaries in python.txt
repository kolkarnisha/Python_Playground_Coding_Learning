Sets in Python
Definition
A set is an unordered collection of unique elements.

Written with {} braces.

No duplicates allowed.

Useful for membership tests, removing duplicates, and mathematical set operations.

Real Use Cases
Removing duplicates from a list.

Fast membership testing (in).

Mathematical operations like union, intersection, difference.
# 1. Creating sets
fruits = {"apple", "banana", "cherry"}
numbers = set([1, 2, 3, 3, 2])  # duplicates removed
print(numbers)  # {1, 2, 3}

# 2. Adding & removing
fruits.add("orange")
fruits.remove("banana")
print(fruits)

# 3. Membership test
print("apple" in fruits)   # True
print("grape" not in fruits)  # True

# 4. Set operations
A = {1, 2, 3, 4}
B = {3, 4, 5, 6}

print(A | B)   # Union → {1,2,3,4,5,6}
print(A & B)   # Intersection → {3,4}
print(A - B)   # Difference → {1,2}
print(A ^ B)   # Symmetric difference → {1,2,5,6}

# 5. Advanced: set comprehension
squares = {x**2 for x in range(6)}
print(squares)  # {0,1,4,9,16,25}

# Dictionaries in Python
# -------------------------------

# 1. Creating dictionaries
student = {"name": "Alice", "age": 22, "grade": "A"}
print(student["name"])  # Alice

# 2. Adding & updating
student["age"] = 23
student["city"] = "Bengaluru"
print(student)

# 3. Removing
del student["grade"]
print(student)

# 4. Iterating
for key, value in student.items():
    print(key, ":", value)

# 5. Dictionary methods
print(student.keys())    # dict_keys(['name','age','city'])
print(student.values())  # dict_values(['Alice',23,'Bengaluru'])
print(student.get("grade", "Not Found"))  # Safe lookup

# 6. Real use case: word frequency
text = "apple banana apple orange banana apple"
freq = {}
for word in text.split():
    freq[word] = freq.get(word, 0) + 1
print(freq)  # {'apple':3, 'banana':2, 'orange':1}

# 7. Advanced: dictionary comprehension
squares = {x: x**2 for x in range(6)}
print(squares)  # {0:0, 1:1, 2:4, 3:9, 4:16, 5:25}
