Set Operations in Python (simple collections -> intelligent collections)
Sets are VERY imp Interns because they automatically handle:
- uniqueness
- filtering
- mathematical operations - Real systems use this heavily interns


A set is an unordered collection of unique values
-> Sets are powerful endukantee real software constantly works with uniqueness and matching

Sets Features for Interns:
 Unordered | No fixed indexing     
 Unique    | No duplicate values   
 Mutable   | Can add/remove values 

Ex raaskondi:
skills = {"Python", "SQL", "AI"}
numbers = {1,2,2,3,3,3}
print(numbers) # {1,2,3} - DUPLICATES AUTOMATICALLY REMOVED

Enduku ee sets companiesloo:
- Sets removes duplicate email IDs
- duplicate usernames
- duplicate product IDs -> Sets solve these problems efficiently

 List                     Set           
 Ordered            | Unordered     
 Duplicates allowed | No duplicates 
 Indexing possible  | No fixed indexing   

BASIC SET OPERATIONS
skills = {"Python", "SQL", "AI"}
1. ADD ELEMENT -> add()
skills.add("FastAPI") 
print(skills) # {"Python", "SQL", "AI", "FastAPI"}
2. ADD MULTIPLE VALUES -> update()
skills.update(["Git", "Docker"])

3. REMOVE ELEMENT -> remove()
skills.remove("SQL") # If item doesn't exist error occurs
4. SAFE REMOVE -> discard()
skills.discard("Java") # No error if missing
5. REMOVE RANDOM ITEM -> pop()
skills.pop() # Since sets are unordered: random element removed
6. CLEAR ENTIRE SET
skills.clear()

7. CHECK EXISTENCE
print("Python" in skills) # Very common operation idi projectsloo

MATHEMATICAL OPERATIONS of Sets -> THIS is where sets become powerful
8. UNION (| or union()) - Combine all unique values
a = {1,2,3,4,1}
b = {3,4,5,1,2}
print(a | b) # {1,2,3,4,5}
print(a.union(b))

''' Used in:
- merging datasets
- combining user permissions
- AI keyword merging ''' 

9. INTERSECTION (& or intersection()) -> Common values only
a = {1,2,3,1,2,14,5}
b = {2,3,4,5}
print(a & b) # {2, 3, 5}
print(a.intersection(b))

'''Massively important in:
- recommendation systems on youTube 
- common skills matching 
- mutual connections on LinkedIn/Instagram/Facebook'''

Mini-Feature-2: ATS Resume Matching Keywords
student_skills = {"Python", "SQL", "AI"}
job_requirements = {"Python", "Git", "SQL"}

matched = student_skills & job_requirements
print(matched)

10. DIFFERENCE (-) -> Values present in first set but not second
a = {1,2,3}
b = {2,3}
print(a - b) # {1}
print(b-a) # {}

Ekkada antee: 
- missing skills
- incomplete requirements
- filtering systems on LinkedIn (normal_users - premium_users)

student_skills = {"Python", "SQL"}
required_skills = {"Python", "SQL", "Git"}
missing = required_skills - student_skills
print(missing) # {'git'}

11. SYMMETRIC DIFFERENCE (^) -> Values NOT common in both sets
a = {1,2,3}
b = {3,4,5}
print(a ^ b) # {1,2,4,5}

12. SUBSET -> TRUE if 'a'set elements exists in 'b' otherwise FALSE
a = {1,2}
b = {1,2,3}
print(a.issubset(b)) # True
print(b.issubset(a)) # False

13. SUPERSET - 
print(b.issuperset(a))

14. DISJOINT SETS -> No common values
a = {1,2}
b = {3,4}
print(a.isdisjoint(b)) # True
