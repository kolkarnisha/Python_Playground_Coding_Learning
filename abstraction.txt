Step 5: With Abstraction
class TV:
    def turn_on(self):
        self.__power_supply()
        self.__motherboard()
        self.__display()

    def __power_supply(self):
        print("Power On")
    def __motherboard(self):
        print("Motherboard Started")
    def __display(self):
        print("Display Activated")

tv = TV()
tv.turn_on()

# Output
Power On
Motherboard Started
Display Activated -> Now the user only calls

tv.turn_on() -> Implementation is hidden anthee kadaa

Step 7: Import abc Module

Step 8: Creating an Abstract Class

    pass

Step 9: Creating an Abstract Method
from abc import ABC, abstractmethod
class Vehicle(ABC):
    @abstractmethod    #Ikkada @abstractmethod menas Every child class must implement the start() method
    def start(self):
        pass

Step 10: Child Class

Step 12: Okayyy Another Real-World Example - Payment Gateway
Suppose meeru building an e-commerce application
Users can pay through - Credit Card, UPI, PayPal, Net Banking
-> Every payment method has a different implementation, but all must support a pay() method

from abc import ABC, abstractmethod
class Payment(ABC):

    @abstractmethod
    def pay(self, amount):
        pass

class CreditCard(Payment):
    def pay(self, amount):
        print(f"Paid ₹{amount} using Credit Card")

class UPI(Payment):
    def pay(self, amount):
        print(f"Paid ₹{amount} using UPI")

class PayPal(Payment):
    def pay(self, amount):
        print(f"Paid ₹{amount} using PayPal")

payments = [
    CreditCard(),
    UPI(),
    PayPal()]
for payment in payments:
    payment.pay(500)

### Ikkada Why use abstraction here?
The checkout system only needs to call: payment.pay(amount)
-> It doesn't care whether the payment happens via UPI, Credit Card, or PayPal. Each class hides its own implementation details

####Python Abstraction Using Abstract Classes
Python provides the abc module (ABC = Abstract Base Class)
-> An abstract class defines what methods must exist, but not how they work
from abc import ABC, abstractmethod
class Payment(ABC):
    @abstractmethod
    def pay(self):
        pass
This class says:Every payment type must implement pay()

#Credit Card Implementation
class CreditCard(Payment):
    def pay(self):
        print("Processing Credit Card Payment")

#UPI Implementation
class UPI(Payment):
    def pay(self):
        print("Processing UPI Payment")

#Net Banking Implementation
class NetBanking(Payment):
    def pay(self):
        print("Processing Net Banking Payment")
payment1 = CreditCard()
payment2 = UPI()
payment3 = NetBanking()

payment1.pay() #Processing Credit Card Payment
payment2.pay() #Processing UPI Payment
payment3.pay() #Processing Net Banking Payment
### Notice ikkada main program only calls pay() -> It doesn't need to know the implementation details for each payment method

Step 19: Interview Questions chudhama finalga
1. What is abstraction?
Abstraction is the process of hiding implementation details and exposing only essential functionality to the user
2. Which module provides abstraction in Python?
The built-in abc module
3. Can we create an object of an abstract class?
No kadaa Attempting to instantiate an abstract class raises a TypeError
4. Which decorator is used for abstract methods?
@abstractmethod
5. Can an abstract class contain normal methods?
Yes. An abstract class can have both abstract methods and fully implemented (concrete) methods
6. Can a child class inherit from an abstract class without implementing all abstract methods?
Yes, but then that child class also remains abstract and cannot be instantiated until all abstract methods are implemented

######Notification System: Suppose a company wants to send notifications
Different notification channels:
- Email
- SMS
- WhatsApp
- Push Notification
# All have the same action: send()

#Abstract class:
from abc import ABC, abstractmethod
class Notification(ABC):
    @abstractmethod
    def send(self):
        pass

##Implementations:
class Email(Notification):
    def send(self):
        print("Sending Email")

class SMS(Notification):
    def send(self):
        print("Sending SMS")

class WhatsApp(Notification):
    def send(self):
        print("Sending WhatsApp Message")

notifications = [Email(), SMS(),WhatsApp()]
for notification in notifications:
    notification.send() -> It doesn't need to know the implementation for each notification type
